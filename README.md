# Harsh Shukla Portfolio

Premium futuristic portfolio for Harsh Shukla, built with Vite, React, TypeScript, Tailwind CSS, Framer Motion, and React Icons.

## Features

- Dark cyberpunk UI with neon purple and blue lighting
- Glassmorphism cards and animated gradients
- Framer Motion reveal, hover, and scroll animations
- Responsive hero, about, skills, projects, timeline, and contact sections
- Cursor glow and scroll progress effects
- Generated resume download button

## Scripts

```bash
npm install
npm run dev
npm run build
npm run preview
```

## Deployment on Vercel

1. Push the project to GitHub.
2. Import the repository in Vercel.
3. Use these settings:
   - Framework preset: Vite
   - Build command: `npm run build`
   - Output directory: `dist`
4. Deploy.

## Notes

- The resume download generates a text-based resume file because no source PDF was provided.
- If you want a real PDF resume, replace the generated download with a static asset or PDF generation step.
